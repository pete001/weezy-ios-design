Founder feedback on build 37: Sets is for buying a set as a whole. Show the full price, the set price and the deal. Pieces should feel like part of one collection, not individual products. Every set gets the full screen and the same information, and each set has its own label. Buying single pieces stays in Charms, Earrings, Hot and Style. Every set is 5 charms + a free chain. Example: Celestial Magic (Moon, Sun, Small Star, Swirl, Swirl), £90 charms + £16 paperclip chain = £106 regular, £80 set price, save £26 (£10 off + the free £16 chain). Most sets save £26.
